## 📌 Project Overview

Momentum is a production-style crowdfunding platform built with modern web
technologies. It enables users to create fundraising campaigns, explore active
campaigns, support meaningful causes, and manage their activities through a
secure dashboard.

The application focuses on:

- Clean UI/UX
- Responsive Design
- Secure Authentication
- Role-based Access
- Fast Performance
- Modern Development Practices

# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/islammdsohan603/-Crowdfunding_Platform_Client_Code.git
```

## Install Dependencies

```bash
npm install
```

## Environment Variables

Create a `.env.local`

```env
NEXT_PUBLIC_SERVER_URL=YOUR_SERVER_URL

NEXT_PUBLIC_BETTER_AUTH_URL=YOUR_AUTH_URL

NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY=YOUR_STRIPE_KEY
```

> Never commit your secrets to GitHub.

---

## Run Development Server

```bash
npm run dev
```

Open

```
http://localhost:3000
```
